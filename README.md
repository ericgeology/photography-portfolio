# Eric Gao Photography

An initial, mobile-friendly photography portfolio prototype with Home, Portfolio, Stories, About, and Contact sections.

## Preview locally

Open `index.html` directly in a browser, or serve this folder with any simple static web server.

## Replace the placeholders

- Replace the Unsplash image URLs in `index.html` (and `app/page.tsx`) with your own photographs.
- Replace `hello@example.com` with your real contact email.
- Replace the placeholder Instagram and Unsplash links.
- Edit the biography and project captions in the same files.

## Deploy free with Vercel

1. Push this folder to a GitHub repository.
2. Import the repository at Vercel.
3. Choose “Other” as the framework preset and use `.` as the output directory.
4. Deploy. Vercel will provide a free `vercel.app` address.

## Deploy free with GitHub Pages

1. Push this folder to a GitHub repository.
2. In the repository, open Settings → Pages.
3. Choose “Deploy from a branch”, then select the main branch and root folder.
4. GitHub will provide a free `github.io` address.
